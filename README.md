# Java Events Platform

Event management platform focused on limited capacity, registrations,
waitlists and event-driven workflows.

## Status

🚧 Product discovery.

The domain, business rules and architecture will be defined incrementally
before implementation.

## Main goals

- Model events with limited capacity
- Handle registrations and cancellations
- Support waitlists
- Explore concurrency and overbooking prevention
- Introduce event-driven workflows where they make sense

## Planned stack

- Java
- Spring Boot
- Kafka
- Redis
